# Referências de origem do Design System Zelo

Mockups aprovados na sessão de 2026-09-25 que definiram o sistema. São **referência visual**, não código de produção
(HTMLs autocontidos, fontes embutidas). A implementação canônica está em `src/themes/` e `src/lib/components/zelo/`.

| Arquivo | O que é |
|---|---|
| `zelopdv-app-light.html` | `/app` desktop, superfície clara com sidebar navy (**variante aprovada**). Clicável; botão inferior alterna para sidebar clara. |
| `app-navy-sidebar.png` / `app-light-sidebar.png` | Capturas 1440×900 @2x das duas variantes. |
| `zelopdv-app-mobile.html` / `app-mobile-pair.png` | `/app` mobile: cabeçalho navy, grade clara, CartBar navy, comanda em sheet com deslizar-para-remover. |
| `zelopdv-morph.html` | Peça de motion (uma forma, 11 estados, 8 compassos a 120 BPM). Abrir com `#navy` para a versão Brand. |
| `beat-sheet.png` / `beat-sheet-navy.png` | Um quadro por batida do motion, versões clara e navy. |
